# 픽카이브

여러 커뮤니티(클리앙, 뽐뿌, 보배드림, 루리웹, 인벤)의 인기글을 모아 보여주는 사이트. [pickchive.pages.dev](https://pickchive.pages.dev)

Astro + TailwindCSS 기반([AstroPaper](https://github.com/satnaing/astro-paper) 테마를 바탕으로 커스터마이징), Cloudflare Pages + Workers(Cron) + D1에 배포됨.

## 로컬 실행

```bash
npm install
npm run dev
```

## 빌드

```bash
npm run build
```
